Make Maximo information easier for applications to use

Organisations often need Maximo information to appear in several applications and user experiences. GraphQL for IBM Maximo provides one application-facing interface over Maximo's existing APIs, keeping the integration detail behind a consistent contract.

GraphQL for IBM Maximo is a production-ready GraphQL API developed by Visualise Info for IBM Maximo 7.6.1.x and IBM Maximo Application Suite Manage. It provides a GraphQL interface over Maximo's existing APIs, allowing applications to query, navigate and update supported Maximo information through a consistent interface.

Bring the right information into view

Applications can request the fields they need, narrow supported lists and work through larger result sets in manageable pages.

Follow connected information

Applications can move between related assets, locations, work orders and service requests through the same interface.

Use a consistent application contract

The GraphQL schema gives consuming applications a common way to work with supported Maximo information while the executor handles Maximo-specific translation.

A more flexible way to work with Maximo

A modern interface, with Maximo underneath

GraphQL for IBM Maximo sits seamlessly on top of your existing architecture. It translates incoming application requests into optimised Maximo OSLC REST API calls, serving data through a single, unified GraphQL schema without modifying your underlying setup.

Maximo remains your untouched enterprise system of record. Modernising the application layer delivers a clear advantage: teams can build fast, modern apps without forcing every consuming experience to understand complex, Maximo-specific integration behaviours.

What the interface supports

  • Selecting the information an application requires
  • Filtering and ordering supported lists
  • Cursor-based pagination across supported information
  • Moving between related Maximo records
  • Supported create, update and delete operations

What it connects

Applications can view all five supported Maximo information areas. The current schema also supports creating and updating assets, work orders and service requests, plus delete operations across all five areas where Maximo permits the change.
